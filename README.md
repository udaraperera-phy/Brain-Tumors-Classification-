# Brain-Tumors-Classification-
in this project, the several type of brain tumors were classified by using XgBoost machine learning model. they are glioma, meningioma,pitiutary and no tumor. 

first of all run the s16113_extract_features.ipynb file to make a feature selection csv file. then run the s16113_ml_model.ipynb file to train the machine learning model
